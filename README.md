# F1 Logbook

A web app where users create an account and build their own Formula 1
"logbook": favorite drivers, circuits, and races. Beyond the personal
part, the app also works as a small F1 encyclopedia — every driver and
circuit has its own profile with real stats and records (fastest lap,
most wins, etc.), populated from a public API.


## What it demonstrates technically

- Object-relational data modeling with SQLAlchemy
- Full CRUD operations across several related entities
- User authentication and authorization (JWT)
- Consuming an external API to populate real data, instead of manual
  data entry
- A backend architecture built with FastAPI

## Current status

Initial infrastructure is in place: FastAPI is connected to
PostgreSQL, and `Driver` has full CRUD endpoints (`GET`, `POST`,
`PUT`, `DELETE`) as a proof that the setup works end to end.

## Data model

| Entity | Description |
|---|---|
| `User` | User accounts |
| `Driver` | Drivers — stats, championships, photo |
| `Circuit` | Circuits — lap records, most-wins stats, photo |
| `Race` | A single race, belongs to a circuit |
| `RaceResult` | One row per driver per race; the podium is this same table filtered to positions 1–3 |
| `DriverSeasonHistory` | One row per driver per season (year-by-year history) |
| `FavoriteDriver` / `FavoriteCircuit` / `FavoriteRace` | Many-to-many join tables between `User` and the entity above |

Full schema and relationships are documented separately in the
project's design doc.

## Data source

Driver, circuit, race, and result data comes from
[Jolpica-F1](https://api.jolpi.ca), a free, public, unauthenticated
API with historical F1 data from 1950 onward.

The app does **not** call this API on every user visit. An
admin-triggered sync fetches the data once (or on demand) and stores
it in the project's own database — the app always reads and writes
against its own data, independent of the external API's availability.

Driver and circuit photos are curated by hand from [Wikimedia Commons](https://commons.wikimedia.org) under
Creative Commons licenses, stored separately from the automated sync.

## Tech stack

- **Backend:** FastAPI
- **ORM:** SQLAlchemy
- **Database:** PostgreSQL
- **Auth:** JWT (password hashing with `passlib`/`bcrypt`, `/me`
  endpoint for the authenticated user)
- **External data:** `requests`/`httpx` against the Jolpica-F1 API
- **API docs/testing:** Swagger UI (auto-generated by FastAPI),
  tested with Postman
- **Deployment:** Render (web service + PostgreSQL)


## Getting started

```bash
git clone <this-repo-URL>
cd f1-logbook
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Create a `.env` file in the project root with your local PostgreSQL
connection string:

```bash
DATABASE_URL=postgresql://user:password@localhost:5432/f1-logbook
```
Then run the server:

```bash
uvicorn app.main:app --reload
```

API docs available at `http://127.0.0.1:8000/docs` once the server is
running.
